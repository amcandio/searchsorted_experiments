# Scripts Used for the Implementations and Benchmarks in the `searchsorted` Blog Post

The following files contain the implementations, tests, and benchmarks used for the [blog post](https://blog.scientific-python.org/numpy/searchsorted/):

- `impl.py`: All NumPy-based implementations used.
- `tests.py`: Tests ensuring consistent behavior across implementations.
- `bench/bench.py`: Benchmarking logic for NumPy-based implementations.
- `bench/bench_cross.py`: Benchmarking logic for cross-library comparisons.
- `images/plot.py`: Plotting scripts.
